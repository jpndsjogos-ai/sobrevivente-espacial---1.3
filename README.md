# Survivor Offline

Jogo estilo Vampire Survivors, 100% offline, feito em HTML5/JavaScript puro
(sem internet, sem anúncios, sem servidor). Compilado para Android (.apk)
automaticamente pelo GitHub Actions.

Veja o passo a passo completo na conversa com o Claude, ou siga o resumo abaixo.

## Resumo rápido

1. Crie um repositório novo no GitHub e suba todos estes arquivos.
2. Vá na aba **Actions** do repositório e espere o workflow "Build APK" terminar.
3. Baixe o arquivo `survivor-offline-apk` gerado — é o seu `.apk`.
4. Transfira para o celular e instale (permitindo "fontes desconhecidas").

O APK gerado é um APK de **debug**, ou seja, já vem pronto para instalar e
testar sem precisar criar chave de assinatura nenhuma.
